🛡️ PhishProbe02 · Solution
⚙️ How it works

Two checks — fast first, deep second

⚡ Stage 1 · under 1 second
Quick check
Pure URL heuristics — homoglyphs (paypa1), shady TLDs, raw-IP hosts, deep subdomains, shorteners, lure words — plus a cache. No browser. This is what the browser extension calls on every link.
🧪 Stage 2 · in the sandbox
Deep scan
The agent really opens the page: full redirect chain, desktop + mobile screenshots, form/field map, network log, blocked downloads. A vision model + text model produce the verdict. Streams live to the UI over SSE.
🔑 The agent loop (all LLM calls) runs in the orchestrator, never in the sandbox. The sandbox only performs browser actions and returns data.

🛡️ PhishProbe04 · Architecture
🧯 Containment · the heart of the scoring

Blast Radius Zero

Visiting an attacker-controlled page is the product — so containment is the product. A compromised page finds nothing to steal and can't break out.
🔒
No secrets
The LLM key lives only in the orchestrator. Sandbox starts with environment={}.
🚫
No internal access
Can't reach host, api/db, private IPs or the metadata endpoint — blocked in-sandbox and by host iptables.
⏱️
Hard limits
Non-root, read-only, cap_drop=ALL, mem/CPU/PID + per-scan & per-action timeouts.
⬇️
Downloads blocked
Download events are logged and cancelled; nothing ever hits disk.
🧬
Injection-proof
Page content enters the prompt as fenced DATA. "Say SAFE" → forced 🔴, a deterministic hard floor.
💥
Destroyed after
Logs saved, then kill() + remove() after every single scan.
🛡️ PhishProbe05 · Containment
☁️ Built on Vultr

Vultr is the control plane — not just hosting

Cloud Compute VMThe entire control plane. Runs Caddy, the Next.js frontend, the FastAPI orchestrator, and launches/destroys every sandbox container via the Docker SDK.
Serverless InferenceEvery LLM call. OpenAI-compatible endpoint. A text model produces the verdict; a vision model analyses screenshots ("which brand does this imitate? login/payment page?").
Docker on the VMOne throwaway, isolated sandbox container per scan. Built from ./sandbox, torn down after each run.
No Claude / OpenAI / other provider is called from the product — all inference goes through api/agent/llm.py, which only ever talks to Vultr.
